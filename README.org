#+title: ox-epub — Org-mode → clean EPUB 3.0 exporter
#+author: Junghan Kim
#+language: en

Export Org-mode documents directly to *EPUB 3.0* from Emacs. A single
=C-c C-e E e= turns the current buffer into a =.epub= that passes
[[https://www.w3.org/publishing/epubcheck/][EPUBCheck]] with *0 errors / 0 warnings*.

This is a maintained fork of [[https://github.com/ofosos/ox-epub][ofosos/ox-epub]]. The original (v0.1.0,
unmaintained since 2018) only emitted the legacy *EPUB 2.0.1* format,
which fails modern EPUBCheck on three structural counts (ARIA =role=
forbidden under XHTML 1.1, SVG forced into foreign-resource fallback,
compressed mimetype). This fork makes the exporter emit valid EPUB 3.0
*natively* — no external post-processing step — and fixes headless
(daemon / =--batch=) export.

* Features

- *Native EPUB 3.0* — =<!DOCTYPE html>= content documents, EPUB3
  package, generated =nav.xhtml= (toc + landmarks) alongside =toc.ncx=.
- *Math as SVG* — =#+OPTIONS: tex:dvisvgm= renders LaTeX to inline SVG.
  No JavaScript, sharp at any zoom, identical across readers.
- *Headless-safe* — exports from =emacs --daemon= / =--batch=. Cover
  image dimensions are read from the PNG/JPEG header, so no graphic
  frame is required (upstream called =image-size=, which aborts headless
  with "Window system frame should be used").
- *Faithful typography* — images, tables (caption + cross-reference),
  footnotes (with backlinks), nested lists, quotes, code blocks,
  emphasis, dashes, smart quotes, and named entities (=&alpha;= …) all
  survive the round-trip and validate as XML.
- *Book figures* — =<figure>/<figcaption>=, figure groups via
  =#+begin_figure=, captions that keep the book's own numbering, and
  =:align left/right/center= mapped to classes (HTML5 has no img =align=).
- *Popup footnotes* — =epub:type="noteref"= references and
  =<aside epub:type="footnote">= notes.
- *Listenable math* — each formula image carries its LaTeX source as
  =alt=, so screen readers and text-to-speech read the formula.
- *Korean / CJK* friendly — Korean labels (그림 / 표 / 각주 / 차례),
  which Org's own export dictionary lacks.
- Works with [[https://github.com/tecosaur/org-glossary][org-glossary]].
- Valid, escaped, unique =dc:identifier= (auto-generates a UUID when the
  =#+UID= is missing or a malformed UUID).

* Requirements

- Emacs 24.3+ and Org 9+.
- The =zip= utility (for packaging).
- For math export: a working =latex= + =dvisvgm= (TeX Live).
- To validate: [[https://www.w3.org/publishing/epubcheck/][EPUBCheck]] (e.g. =nix run nixpkgs#epubcheck -- book.epub=).

#+end_src

#+begin_src emacs-lisp
;; config.el
(use-package! ox-epub :after ox)
#+end_src

** straight.el

#+begin_src emacs-lisp
(straight-use-package
 '(ox-epub :type git :host github :repo "junghan0611/ox-epub"))
#+end_src

** Manual

Clone the repo and =(add-to-list 'load-path "/path/to/ox-epub")=, then
=(require 'ox-epub)=.

* Usage

With the current Org buffer, hit =C-c C-e E e= (or =M-x
org-epub-export-to-epub=) to produce =<file>.epub=.

** Document keywords

Required:

| Keyword      | Meaning                                              |
|--------------+------------------------------------------------------|
| =#+TITLE=    | document title                                       |
| =#+AUTHOR=   | author / creator                                     |
| =#+LANGUAGE= | language tag (RFC 3066), e.g. =ko=, =en=             |
| =#+DATE=     | publication date                                     |
| =#+UID=      | unique id (URL / =urn:uuid:…=). Auto-UUID if missing |

Optional:

| Keyword         | Meaning                                              |
|-----------------+------------------------------------------------------|
| =#+SUBJECT=     | subject matter                                       |
| =#+DESCRIPTION= | description                                          |
| =#+PUBLISHER=   | publisher                                            |
| =#+LICENSE=     | rights / copyright                                   |
| =#+EPUBCOVER=   | cover image (PNG recommended; 1:1.6, e.g. 1600x2560) |
| =#+EPUBSTYLE=   | extra CSS file(s)                                    |

Heading levels map to the EPUB chapter structure; =#+OPTIONS: H:4=
controls TOC depth, =toc:t num:t= the table of contents and numbering.

** Math

- Inline: =\( ... \)=
- Display: =\[ ... \]= (=aligned=, =\int=, =\nabla=, … supported)
- Set =#+OPTIONS: tex:dvisvgm= to render formulas to SVG.

** Figures

- A captioned standalone image becomes =<figure>= + =<figcaption>=.
- Several images that form one figure go in a =#+begin_figure= block; the
  block's =#+caption= becomes the group caption, sub-figures sit two per row.
- A caption that already starts with its own label (=그림 1-1:=,
  =Table 2.3=, see =org-epub-caption-label-regexp=) gets no second,
  Org-generated number — paste book captions as they are.
- =#+attr_html: :align left|right|center= floats or centres the image.

** Headless / batch export

#+begin_src sh
emacs --batch -l ox-epub.el --eval \
  "(with-current-buffer (find-file-noselect \"book.org\")
     (org-epub-export-to-epub))"
#+end_src

* Sample & verification

A full-feature fixture lives in =sample/= — it exercises images, figure
groups, alignment, SVG math (inline + display), tables, footnotes (named,
inline, multi-paragraph), an org-glossary glossary, TOC, Korean text,
quotes, lists, code blocks, emphasis, dashes and entity conversion in one
file.

#+begin_src sh
cd sample
# (re)generate the cover/figure images — needs python + Pillow
python gen-images.py
# export via a running daemon …
emacsclient -s <socket> --eval \
  "(progn (load \"../ox-epub.el\")
     (with-current-buffer (find-file-noselect \"sample.org\")
       (org-epub-export-to-epub)))"
# … then validate
nix run nixpkgs#epubcheck -- sample.epub   # => 0 errors / 0 warnings
#+end_src

* What changed vs. upstream

EPUB 2.0.1 → EPUB 3.0 lift, folded into the exporter itself:

- Package =version="3.0"=, required =dcterms:modified=, valid/escaped
  =dc:identifier= (UUID normalisation), empty =dc:*= elements dropped.
- =image/svg= → =image/svg+xml= so SVG (math) is a core media type.
- =<!DOCTYPE html>= + =xmlns:epub= content documents; named HTML
  entities converted to literal characters (XML-safe).
- Generated =nav.xhtml= (toc + landmarks); =<guide>= kept only for a
  cover (EPUB2 reader backward compatibility), never empty.
- Cover: =properties="svg"/"cover-image"=, non-empty =<title>=, real
  aspect-ratio =viewBox=; dimensions read from file header (headless).
- mimetype stored first with no trailing newline.
- Obsolete presentational table attributes suppressed.
- XHTML5 with =html5-fancy=: =<figure>=, =<figcaption>=, =<nav>=,
  EPUB3 =aside= footnotes; img =align= → =org-align-*= class.
- Special-block captions kept (ox-html drops them); detached paragraphs
  (org-glossary terms) no longer wrap a =<p>= inside an =<a>=.
